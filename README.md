# Abraar Khan: Cyber / Secure AI Portfolio

Single-page portfolio for Mohammed Abraar Khan, ML and AI systems engineer focused on securing RAG, LLM agents and untrusted-code execution.

It is one static file, `index.html`, with no build step. Open it in a browser, or serve the folder with any static host (for example GitHub Pages: Settings, Pages, deploy from the `main` branch root).

Fonts load from Google Fonts. Light and dark themes follow the system setting, with a toggle in the header.
